## 📝 Description
Aplikasi yang bertujuan untuk memudahkan penggunanya mencatat riwayat olahraga (lari) yang telah dilakukan

## ✨ Daftar & Deskripsi Fitur
### 🏃 Core Run Tracking (CRUD)
*   **Tambah Data (Create):** Memasukkan data lari (Judul, Lokasi, Tanggal, Jarak, dan Durasi).
*   **Tampilkan Data (Read):** Menyajikan riwayat aktivitas dalam bentuk daftar yang rapi.
*   **Perbarui Data (Update):** Fitur untuk mengedit detail aktivitas lari yang sudah tersimpan.
*   **Hapus Data (Delete):** Menghapus catatan aktivitas dari database.

### 👤 User Management & Profile
*   **UI Profile:** Halaman khusus untuk menampilkan statistik dan identitas pengguna.
*   **Ubah Profile:** Fitur untuk memperbarui informasi personal (Nama/Bio).
*   **Unggah Foto Profil:** Implementasi integrasi galeri untuk mengganti foto profil secara dalam aplikasi.

### 💾 Persistence & UI
*   **Room Database:** Penyimpanan data lokal yang persisten.
*   **Material Design 3:** Antarmuka modern dengan gaya dark-mode atletik yang responsif.

## ⚙️ Tech Stack
- Kotlin
- Model-View-ViewModel
- Room Persistence Library
